1. Illegal vs. Unethical

Misconception Alert: Many students think if an app feature is legal, it must be ethical. False. An app might legally harvest your data (because you clicked "Agree" on a 50-page document), but users still consider it highly unethical.

2. Algorithmic Decision Making

How do we program a computer to handle ethical dilemmas or system failures? We use Nested Logic. We check one condition, and based on that result, we check another.

Structure of a Nested If

if incident == True:
    if severity == "High":
        page_admin()
    else:
        log_error()
