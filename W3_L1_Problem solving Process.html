Teacher Model: The Attendance Tracking App

⏱ Click to Start (06:00) Points: 10 pts

Teacher Think-Aloud: Observe Ms. Ramesh's sequential breakdown for designing a school attendance verification script. Notice specifically how the Reflect stage exposes an unhandled edge-case and forces a loop back to Prepare.

[I DO: Step 1] DEFINE Requirement Identification

Teacher Think-Aloud: "What is my goal? Mark students present or absent quickly. Who is the user? Classroom teachers. What are the constraints? Speed is crucial, and late arrivals must not be permanently marked absent."

[I DO: Step 2] PREPARE Algorithm Design

Teacher Think-Aloud: "I sketch a flow: Prompt teacher for arrival status ('P' for Present, 'A' for Absent). I plan a Python conditional check using an if / else structure."

[I DO: Step 3] TRY (Teacher Prototype Code) Python 3.10 
status = input("Enter student status (P/A): ").upper()
if status == "P":
    print("Record saved: Present.")
else:
    print("Record saved: Absent.")
[I DO: Step 4] REFLECT (Iterative Loop Back) Edge-Case Evaluation

Teacher Think-Aloud: "Does this work if a student arrives 15 minutes late? If the teacher enters 'L', the script executes the else branch and mistakenly registers them as absent! Reflection: I must loop back to Prepare to add an elif status == 'L' branch."
