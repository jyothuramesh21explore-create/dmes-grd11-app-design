STAGE 4 • EXPLICIT INSTRUCTION (10 MIN)

Information Machines vs. Physical Tools

⏱ 10:00

Core Concept: Computers were historically room-sized numerical calculators (like ENIAC programmed by Bartik and Spence). Today, computers are embedded into consumer appliances. A computer is formally defined as: a machine that works with information to solve problems.

The Universal Misconception: A computer is NOT defined by having a screen, keyboard, mouse, or internet connectivity! A toaster or hand-crank sharpener transforms electricity into heat or physical friction. A digital microwave or autonomous vehicle reads sensors, runs logic, and changes state—making them true embedded computers.

Guiding Checkpoint Question: If a machine runs solely on gears, pulleys, or simple closed analog circuits without memory or data transformation, can it be a computer?

STAGE 4 • EXPLICIT INSTRUCTION (10 MIN)

The Four Core Computational Processing Engines

⏱ 10:00

Processing is the algorithmic thinking work connecting input to output. The four universal operations are:

1. If/Then (Conditionals)

Branching execution based on Boolean truth: IF score >= 50 THEN "Pass"

2. Comparing

Evaluating mathematical magnitude or equality: user_val > secret_num

3. Finding a Match

Scanning collections/databases for an identical record query (e.g., authentication).

4. Counting (Accumulating)

Incrementing frequency counters on trigger events: taps = taps + 1

STAGE 5 • TEACHER MODEL (I DO)

Deconstructing: "Guess the Number" Game

⏱ 05:00

Step-by-Step Logic Trace:

// Target secret_num = 75 INPUT: user_guess = 42 PROCESSING ROUTINE: 1. COMPARING: Compare user_guess (42) against secret_num (75) 2. IF/THEN BRANCHING: IF user_guess < secret_num THEN OUTPUT: "Too Low! Guess higher." ELSE IF user_guess > secret_num THEN OUTPUT: "Too High! Guess lower." ELSE OUTPUT: "Correct! You won!" 3. COUNTING: attempts_counter = attempts_counter + 1 OUTPUT: Render "Too Low!" banner & update attempt badge to "Turn 1"

Notice how this single action orchestrated THREE processing types in nanoseconds: Comparing, If/Then, and Counting!

STAGE 4 • EXPLICIT INSTRUCTION (10 MIN)

Data Persistence & The Unified IOSP Model

⏱ 10:00

Core Concept: Storage is information saved for the computer to use in the future. All computing systems on Earth operate through the unified four-part cycle: Input, Output, Storage, and Processing (IOSP).

The Software Storage Rule of Thumb:
• STORE IT: If it rarely changes, if the user expects multi-session persistence, or if it represents historical state (user profiles, achievements, friend lists).
• DO NOT STORE (Fetch Live): If the data fluctuates dynamically every second, if it can be fetched via live API, or if storing it creates severe security/privacy risks (e.g., live weather, real-time GPS coordinates, temporary search queries).
